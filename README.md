# temporary — مؤقت القط

تطبيق أندرويد بسيط: تحدد مدة أو وقت، ويطفي الواي فاي / بيانات الجوال / البلوتث تلقائيا.
يشتغل كـ **خدمة إمكانية الوصول (Accessibility Service)**، بدون Shizuku وبدون كمبيوتر.

## تنزيل التطبيق
بعد كل push على `main` يبني GitHub Actions ملف APK تلقائيا:
- **Releases ← Latest build ← temporary.apk** (رابط مباشر)
- أو **Actions ← آخر تشغيل ← Artifacts ← temporary-apk**

## التشغيل لأول مرة
1. ثبّت الـ APK (فعّل "السماح بالتثبيت من مصادر غير معروفة").
2. افتح التطبيق واضغط **افتح إعدادات إمكانية الوصول** ← الخدمات المنزّلة ← **مؤقت القط** ← شغّلها.
   - أندرويد 13 وما فوق: لو الخيار رمادي، روح لـ *معلومات التطبيق ← ⋮ ← السماح بالإعدادات المقيّدة* ثم ارجع.
3. اختر الأشياء اللي تبي تتطفى، وحدد المدة، واضغط **شغّل المؤقت**.
4. جرّب أول بزر **جرّب الآن**: يطفي فوراً ويعرض النتيجة تحت.

## كيف يشتغل
عند الوقت المحدد يصحّي الشاشة ويفتح لوحة الإعدادات السريعة ويضغط زر الواي فاي / البيانات / البلوتث بدالك،
وإذا ما لقاه يجرب صفحات الإعدادات. بعد كل محاولة يتأكد من الحالة الفعلية، فما يشغّل شي بالغلط.
لو الشاشة كانت مقفولة قبل ما يبدأ، يقفلها من جديد بعد ما يخلص.

## ملاحظات
- لو الجوال عليه قفل (PIN / بصمة)، بعض الأزرار (خصوصا البيانات) ممكن تحتاج فتح القفل. الأضمن جوال قفله سحب بسيط، أو الأزرار تشتغل من شاشة القفل.
- بعض الجوالات (شاومي / هواوي / أوبو ...) تقتل الخدمات الخلفية: فعّل للتطبيق "التشغيل التلقائي" وأوقف "توفير البطارية".
- الأسماء تُقرأ بالعربي والإنجليزي. لو لغة النظام أو شكل الإعدادات مختلف وما اشتغل، رسالة الخطأ تحت زر التجربة تقول وش شاف التطبيق.
- لو أعدت تشغيل الجوال ينلغى المؤقت.
