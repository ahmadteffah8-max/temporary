# temporary — مؤقت القط

تطبيق أندرويد بسيط: تحدد وقت أو مدة، ويطفي الواي فاي / بيانات الجوال / البلوتث تلقائيا.
يشتغل على أندرويد 6 وما فوق (مجرب التصميم على أندرويد 9 فما فوق).

## تنزيل التطبيق
بعد كل push على `main` يبني GitHub Actions ملف APK تلقائيا:
- **Releases ← Latest build ← temporary.apk** (رابط تنزيل مباشر، أسهل من الجوال)
- أو **Actions ← آخر تشغيل ← Artifacts ← temporary-apk**

ثبّت الـ APK (فعّل "السماح بالتثبيت من مصادر غير معروفة").

## تشغيل Shizuku (مرة وحدة بعد كل إعادة تشغيل للجوال)
1. نزّل تطبيق **Shizuku** (Play Store أو GitHub).
2. **أندرويد 11 فما فوق:** من خيارات المطور فعّل *Wireless debugging* ثم افتح Shizuku واضغط *Start* واتبع الخطوات (بدون كمبيوتر).
3. **أندرويد 10 وما قبل (مثل أندرويد 9):** يحتاج كمبيوتر مرة وحدة. وصّل الجوال بالـ USB مع تفعيل *USB debugging* ثم نفّذ:
   ```
   adb shell sh /sdcard/Android/data/moe.shizuku.privileged.api/start.sh
   ```
4. افتح "مؤقت القط" واضغط **منح الصلاحية**.

## ملاحظات
- المؤقت يستعمل `setAlarmClock` فيشتغل في الوقت المحدد حتى لو التطبيق مقفول أو الجوال في وضع النوم.
- بدون Shizuku: الواي فاي يتطفى في أندرويد 9 وما قبل، والبلوتث في أندرويد 11 وما قبل. بيانات الجوال تحتاج Shizuku دايما.
- لو أعدت تشغيل الجوال ينلغى المؤقت وShizuku يتوقف، فشغّله من جديد.
