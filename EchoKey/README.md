# EchoKey – Soundboard & Virtual Microphone

برنامج Windows خفيف (C# / .NET 10 / WPF / NAudio) لتشغيل ملفات صوتية بالاختصارات العامة وإرسالها عبر **VB-CABLE** كميكروفون افتراضي، مع دمج صوت ميكروفونك الحقيقي.

> **حالة الاختبار (مهم):** كُتب الكود في بيئة Linux بدون .NET SDK ولا Windows، لذلك **لم يُترجم (compile) ولم يُشغَّل ولم تُختبر أي ميزة بعد**. قائمة الفحص في آخر هذا الملف توضح ما يجب اختباره على جهازك. أول خطوة هي البناء؛ إن ظهرت أخطاء ترجمة فهي متوقعة في أول مرة ويسهل إصلاحها.

## المتطلبات
- Windows 10 / 11 (64-bit)
- [VB-CABLE](https://vb-audio.com/Cable/) (مجاني) لإنشاء الميكروفون الافتراضي
- للبناء: [.NET 10 SDK](https://dotnet.microsoft.com/download)

## البناء (إنتاج EXE)
**على جهازك:** شغّل `build.bat` فينتج:
- `publish\framework-dependent\EchoKey.exe` – صغير، يحتاج .NET 10 Desktop Runtime
- `publish\self-contained\EchoKey.exe` – أكبر، يعمل بدون تثبيت .NET

**عبر GitHub:** ارفع المجلد إلى مستودع؛ ملف `.github/workflows/build.yml` يبني الملفين على `windows-latest` ويرفعهما كـ Artifacts.

## التثبيت والإعداد
1. ثبّت VB-CABLE: فك الضغط ← `VBCABLE_Setup_x64.exe` بزر الماوس الأيمن ← Run as administrator ← Install Driver ← أعد تشغيل Windows.
2. شغّل `EchoKey.exe`. يظهر في أعلى النافذة مؤشر أخضر إذا اكتُشف الكابل (وإلا تظهر التعليمات).
3. في اللعبة/Discord/OBS اختر **CABLE Output (VB-Audio Virtual Cable)** كميكروفون.
4. في EchoKey ← الإعدادات اختر **ميكروفونك الحقيقي**. جهاز الإخراج (CABLE Input) يُختار تلقائيًا.

البرنامج **لا يغيّر** أي إعداد صوت في Windows. الكابل الافتراضي مستبعد من قائمة الميكروفونات لمنع حلقة صدى.

## الاستخدام
- **إضافة أصوات:** اسحب ملفات (أو مجلدًا) إلى النافذة أو زر «إضافة أصوات». الصيغ: MP3, WAV, OGG, OGA, FLAC (حتى 5 دقائق للملف). تُنسخ الملفات إلى `%APPDATA%\EchoKey\Sounds`.
- **الاختصار:** اضغط الزر الصغير في البطاقة، ثم اضغط التركيبة (F2، Ctrl+F1، Alt+Q …). يُرفض الاختصار المكرر مع تنبيه، وإن كان مستخدمًا في برنامج آخر يتحول لونه للأحمر.
- **التشغيل:** كل ضغطة تبدأ نسخة جديدة من البداية، حتى فوق نسخة تعمل (Overlap/Spam) دون حد منخفض؛ حد الأمان 512 صوتًا متزامنًا. الإيقاف فقط عبر «إيقاف الكل».
- **«لوحة الأصوات»** يوقف/يشغّل التشغيل كله، و**«الاختصارات»** يحرر المفاتيح للنظام مع بقاء التشغيل اليدوي، وهما مستقلان.
- **الميكروفون:** زر كتم مستقل عن الأصوات + مستوى صوت منفصل للميكروفون وللأصوات (حتى 200%) ولكل ملف.
- **معاينة:** زر السماعة يشغّل الصوت على جهاز التشغيل الافتراضي لديك فقط، دون إرساله للميكروفون الافتراضي.
- **التصنيفات:** زر + في الشريط الجانبي؛ كليك يمين على تصنيف لإعادة تسميته/حذفه؛ كليك يمين على صوت للنقل/الترتيب/الحذف.
- **الخلفية:** إغلاق النافذة يخفيها إلى System Tray (قابل للتعطيل). أيقونة الـ Tray: فتح/تشغيل/إيقاف/إغلاق. «التشغيل مع Windows» من الإعدادات (يبدأ مصغّرًا).

## ملاحظات تقنية
- الصوت: WASAPI Shared، مزج بـ 48kHz/ستيريو/Float، مع limiter بسيط. المخزن الافتراضي 40ms (قابل للتعديل من الإعدادات؛ ارفعه عند سماع تقطيع). تأخير الميكروفون الحقيقي يتبع ذلك + حوالي 20ms التقاط.
- الذاكرة: الأصوات تُفك ترميزها إلى الذاكرة لبدء فوري، بميزانية ثابتة ≈96MB مع إخلاء الأقل استخدامًا.
- الاختصارات تستخدم `RegisterHotKey`: تعمل مع الألعاب الاعتيادية، لكن **إذا كانت اللعبة تعمل «كمسؤول»** شغّل EchoKey كمسؤول أيضًا. بعض الألعاب ذات مضاد الغش القوي قد تحجب المفاتيح.
- FLAC و MP3 عبر مكوّنات Windows الأصلية (Media Foundation/ACM)، وOGG/OGA عبر NVorbis.
- ملفات البيانات: `%APPDATA%\EchoKey\settings.json` و `library.json`، وسجل الأخطاء `error.log`.

## قائمة الاختبار المطلوبة على Windows (لم تُنفَّذ بعد)
- [ ] البناء بدون أخطاء، وتشغيل الـ EXE
- [ ] اكتشاف VB-CABLE، وظهور التعليمات عند غيابه
- [ ] اختيار الميكروفون، وسماع صوتك + الأصوات في تطبيق يسجل من «CABLE Output»
- [ ] استيراد MP3 / WAV / OGG / OGA / FLAC بالسحب والإفلات ودفعة واحدة
- [ ] Spam وOverlap لنفس الاختصار، وتزامن أصوات مختلفة، و«إيقاف الكل»
- [ ] الاختصارات العامة داخل لعبة، وCtrl/Alt/Shift، وكشف التعارض
- [ ] تشغيل/إيقاف «لوحة الأصوات» و«الاختصارات» بشكل مستقل، وكتم الميكروفون دون التأثير على الأصوات
- [ ] الـ Tray، والتشغيل مع Windows، وحفظ كل شيء بعد إعادة التشغيل
- [ ] العربية RTL والإنجليزية LTR
- [ ] ثبات لعدة ساعات، واستهلاك الذاكرة/المعالج، وفصل/توصيل الميكروفون أثناء التشغيل
